# Selected v2 candidate interface delta

Use `contracts/abi/orakl-v1-selected-candidate`, generated from **SelectedMarketFactory** plus ProtocolConfig. Existing P0.3 candidate files remain historical and are not the new selected release. Legacy QiePredictionMarket/frontend/Testnet ABI and manifests remain unchanged. Addresses and production network remain null; deployment and activation authorization false. No proxy, migration or live contract replacement is performed.

The selected constructor still accepts one IProtocolConfig address, but validates a fixed tier/ratios. Config keeps its existing ABI and release controls. Market/position/bond tuples and state/outcome enums retain order. Existing predict/create/evidence/finality/claim selectors are retained. Existing base MarketFactory behavior remains P0.3; selecting its ABI/address does not opt into economics v2.

Behavior changes in selected only: challengeResult accepts `value>=Cmin`, one tranche/address, both PROPOSED and DISPUTED before D; later stakes never reset timers. CHALLENGE `getBond` now reverts because a global single owner is invalid. `getChallengeStake(id,owner)` returns amount/prefixBefore/claimed; `getBondEntitlement(id,kind,owner)` quotes remaining terminal bond entitlement. `claimBond` CHALLENGE now selects caller's own tranche. Proposal claim may include S or be zero; creator gets K. A zero entitlement can be acknowledged once without native transfer. Do not show full principal refund as universal after a disputed valid binary result.

New getters expose pilot/global/per-arb budgets, current exposure, release flag, final disposition and S. New events: ChallengeStakeAccepted (all tranches), SelectedSettlement (fixed disposition), ExposureReleased (including zero pool). Continue to index original MarketChallenged only as first transition; do not treat it as all challenge capital. Event-only evidence remains distinct from a bonded objection. Keep the original gate semantics: protective challenge admission must not be disabled solely by a failed live role getter; explicit pause/epoch still block bonds. D is exclusive for intake, inclusive for arbitration; A exclusive for arbitration.

Off-chain tooling must bind the verified selected runtime plus config, chain, source/compiler/artifact digest, full event identity and canonical block history; sums in the indexer are projections only. Observe cap contention, expired nonterminal markets requiring cancellation and terminal unclaimed custody separately. The exact generated selectors/topics/tuples/hashes are in the selected manifest. Owner production amounts, genuine Safe admission, network/wallet/gas/finality/indexing/evidence/legal/audit gates remain blocked.
